# LatAm Grid Overview

Transmission-line mobile coverage maps by country.

- **Dominican Republic**: 2,272 km of transmission lines ($\ge 132\text{ kV}$) vs cellular coverage.
- **Uruguay**: 5,028 km of transmission lines inside Uruguay vs cellular coverage.
- **Peru — Cellular Coverage**: 22,212 km of transmission lines ($\ge 138\text{ kV}$, SEIN) vs cellular coverage.
- **Peru — Grid Ownership**: 22,321 km of transmission lines categorized by concessionaire/operator (Grupo ISA, Celeo, Mining, State Utilities).
